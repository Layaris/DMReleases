Come installare

Le app non passano dagli store: si installano dai file pubblicati qui.

Android (APK)

  1. Scarica il file .apk dalla pagina dell'app.
  2. Aprilo e, la prima volta, consenti l'installazione da questa origine.
  3. Tocca Installa.
  4. Per aggiornare installa il nuovo APK sopra quello vecchio: stessa firma, i dati restano.

iPhone (IPA)

  1. Installa SideStore (o AltStore, Sideloadly).
  2. Scarica il file .ipa e aprilo con SideStore › My Apps › +.
  3. Autorizza il profilo in Impostazioni › Generali › VPN e gestione dispositivi.
  4. Con un Apple ID gratuito rinnova ogni 7 giorni (i dati restano).
