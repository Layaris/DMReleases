Come aggiungere un comando

  1. Scarica il file .shortcut sull’iPhone e aprilo in Comandi Rapidi.
  2. Configura l’indirizzo, il conto o le app richieste nella guida del comando.
  3. Per gli avvisi automatici collega il trigger Notifica alle app desiderate. I file Driver richiedono di ricreare questo collegamento dopo l’importazione.
  4. Disattiva le vecchie versioni dello stesso comando e prova un solo evento alla volta.

Prima di usarli

  • Ledgy: serve un server Ledgy configurato; inserisci il tuo indirizzo personale all’importazione.
  • Driver: richiede Actions di Sindre Sorhus. Riproduce solo il messaggio personalizzato incluso; puoi modificarlo. Dopo l’avviso la suoneria torna al 50% fisso. Gli aggiornamenti delle attività in tempo reale vanno distinti dalle notifiche che avviano il comando.
